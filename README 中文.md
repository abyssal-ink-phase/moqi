# 墨棋 (Ink Chess)

> **非对称三维文明生存策略游戏**  
> 设定于《渊墨纪元》宇宙——在蔓延的墨潮之下，考验文明的战略远见。

[🌐 查看英文版](README.md)

## 墨棋是什么？

墨棋是一款**回合制三维非对称策略游戏**，在可扩展的立方体棋盘上进行（最大可达 99×99×99）。每位玩家控制一枚**文明核心**和 26 个可自定义单位，选自七种独特兵种。目标：在逐渐吞噬棋盘的**墨潮**威胁下，成为最后存活的核心。

**核心特色：**

- 真三维移动与战斗（X/Y/Z 三轴）
- 7 种独特兵种，各具特殊能力
- 战争迷雾、地雷布设、空间扩张
- 动态墨潮天灾——移动、吞噬、膨胀
- AI 对手与本地热座多人对战
- 悔棋、存档与读档
- 基于 Three.js 的完整交互式前端

```bash
# 环境要求：Python 3.8+, Go 1.18+

git clone https://github.com/abyssal-ink-phase/moqi.git
cd moqi
pip install flask pyinstaller  # 如需打包
python launcher.py
# 浏览器访问 http://localhost:8080
```

> **注意：** 后端使用 Go 编写（`engine.go`、`board.go`），首次运行时会自动编译。若二进制文件不存在，`launcher.py` 会自动构建。

## 规则概览

### 棋盘

- 初始尺寸：`[3 × (3 + 玩家数)]³`（例如双人局为 18×18×18）
- 最大扩张：99×99×99（超过后外围迷雾永久锁定，无法继续扩张）

### 兵种（每位玩家固定 1 枚核心 + 26 个自定义单位）

| 兵种 | 移动方式 | 特殊能力 |
|------|----------|----------|
| **文明核心** | 任意方向移动 1 格 | 被摧毁则玩家淘汰，墨潮边长 +5；每存活 2 回合向播种方舟广播生产授权 |
| **勘测兵**（兵） | 正交方向移动 1 格 | 【隔空切割】跳过 1 格空格击杀后方目标；【9³ 绝禁安全区】使敌方地雷无法布设；【5³ 照明区】强制显形敌方地雷，可远程清雷（清雷不计入死亡计数） |
| **星航者**（车） | 任意方向直线无限移动（不可越子） | 【相位跃迁】与核心直线换位（无阻挡时）；【舰队转移】携带 3×3×3 范围内最多 25 个己方单位整体移动 |
| **脉冲炮**（炮） | 任意方向直线无限移动 | 【三维炮架】与目标之间需恰好有 1 枚棋子作为炮架（地雷不可作炮架）；击杀后自身不移动 |
| **超空间漫游者**（马） | 无限连跳（需相邻棋子作跳板）；无跳板时仅能移动 1 格 | 【空间拓荒】停留于迷雾边缘可炸开 3×3×3 新空间；可见地雷可作跳板但踩中即死 |
| **格致构型者**（工兵） | 任意方向最多 3 格（无视阻挡） | 【布设地雷】落点布置隐形永久地雷；地狱模式：以落点为中心在 7×7×7 范围内任意空位布雷 |
| **播种方舟**（种兵） | 非生产回合：任意方向最多 6 格；生产回合：移动力强制为 0 | 【文明播种】收到核心授权后，在相邻 6 格之一生成指定兵种（不可生产核心和地雷）；可自我复制 |

### 星航者【舰队转移】碰撞判定

| 落点情况 | 结果 |
|----------|------|
| 敌方地雷 | 车与车上所有棋子全灭 |
| 敌方非核心单位 | 车、车上所有棋子、目标格敌方单位同归于尽 |
| 敌方核心 | 车上所有棋子全灭，核心绝对安全，不触发边长 +5 惩罚 |
| 空车状态走到敌方核心 | 可击杀核心，触发边长 +5 |

### 墨潮天灾法则

- **降临时机**：开局前 `(玩家数 + 1)` 回合在场外，第 `(玩家数 + 2)` 回合在棋盘边缘随机生成并开始移动
- **移动逻辑（双重引力）**：先向 XY 平面最近单位横向移动 1 格，再向 Z 轴最近单位纵向移动 1 格
- **吞噬结算**：两次位移后，墨潮立方体笼罩范围内的所有棋子/地雷立即湮灭
- **边长扩张**：
  - 自然膨胀：2~3 人每 3 回合 +1；4~6 人每 4 回合 +1；7~10 人每 5 回合 +1
  - 战场献祭：全局累计死亡 10 个单位，边长 +1（勘测兵清雷不计数）
  - 核心引爆：任意核心被击杀/吞噬，边长暴涨 +5
- **扩张方向**：优先向最近单位的 Z 轴方向蔓延；无 Z 轴差则判断 X 轴，最后 Y 轴
- **终局条件**：墨潮边长达到 99 或覆盖所有有效坐标时游戏结束

### 胜利条件

- **唯一幸存者**：最后存活的文明核心所属玩家获胜
- **极乐之局（全员覆灭）**：若墨潮吞噬最后一枚核心，则所有玩家平局（文明全灭）
